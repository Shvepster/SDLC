## Описание проекта

Утилита для инвертирования слов — десктопное Java-приложение с графическим интерфейсом (Swing), предназначенное для пословного разворота текста в предложении с сохранением знаков препинания и структуры разделителей. Архитектура построена по паттерну MVC с активной моделью (Observer), приложение поддерживает валидацию данных и запоминание последнего успешного ввода.
