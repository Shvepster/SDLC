## Описание проекта

Проект представляет собой десктопное Java Swing приложение для пословного инвертирования текста в предложении с сохранением структуры разделителей, пробелов и знаков препинания.

### Основные возможности

* **Пословный разворот:** инвертирование каждого слова в предложении без изменения позиций знаков препинания и пробелов.
* **Удобный ввод данных:** отдельное модальное окно с сохранением и автоматическим восстановлением текста предыдущего ввода.
* **Валидация:** проверка ввода на пустую строку и отсутствие слов с выводом информативных сообщений об ошибках.
* **Архитектура MVC:** разделение логики по паттерну Model-View-Controller с активной моделью (паттерн «Наблюдатель» через `ModelListener`).
