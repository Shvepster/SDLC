Дисциплина: Жизненный цикл разработки программного обеспечения
Тема: Инвертирование слов
Проект представляет собой десктопное Java Swing приложение для пословного инвертирования текста в предложении с сохранением структуры разделителей, пробелов и знаков препинания. Реализована возможность ввода текста через отдельное диалоговое окно с сохранением и восстановлением последнего корректного ввода. Поддерживается валидация входных данных на пустую строку и отсутствие слов с выводом модальных сообщений об ошибках, а архитектура системы построена по паттерну MVC с активной моделью.
